# Brown Bear Rhoticity Pronunciation Website

GitHub Pages-ready website with:

- UK RP vs US GA r-sound comparison
- Cambridge-style pronunciation cards
- embedded Brown Bear PDF viewer section
- page-by-page reading practice
- UK / US text-to-speech buttons
- highlighted r-related words linking back to pronunciation cards

## Files

- `index.html`: main website
- `assets/pages/`: rendered PDF page images
- `assets/pdf/brown-bear-pages-1-13.pdf`: original uploaded PDF copy
- `.nojekyll`: tells GitHub Pages to serve static files directly

## Upload

Upload all files and folders in this package to the root of your GitHub repository, then enable GitHub Pages from Settings > Pages.
