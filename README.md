# Brown Bear Rhoticity Pronunciation Website

This version uses:

- real audio / Cambridge fallback for individual word pronunciation
- system voice for full-page UK / US reading
- embedded PDF page images
- highlighted /r/ words

- `index.html`
- `.nojekyll`
- `README.md`
